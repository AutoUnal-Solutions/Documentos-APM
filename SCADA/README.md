  <li> Interfaz HMI </li>
  El interfaz HMI presenta en su vista principal una imagen superior representativa del sistema automatizado, en el cual es posible visualizar el estado (encendido o apagado) de cada seccion de las bandas transportadoras y las maquinas CNC. Tambien en la parte superior derecha se muestra un Start y Stop General y el estado del sistema representado por un motor.
